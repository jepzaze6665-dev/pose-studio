## ภาพรวม: ปรัชญาเดียวที่อยู่เบื้องหลังทุกคลิป

**"วาดของน้อยชิ้นครั้งเดียว แล้วให้ข้อมูลกับโค้ดขยายผลเป็นพันๆ แบบ"**

| คลิป | ศิลปะที่วาด (น้อย) | ข้อมูล/กฎ/โค้ด (ทวีคูณ) | ผลลัพธ์ |
|---|---|---|---|
| Rig | ชิ้นส่วน 6 ชิ้น/ชุด | มุมกระดูก ~11 ตัวเลข/ท่า | 248 ท่า × 144 ชุด |
| แมพ | ของ 14 ชิ้น | ใบสั่ง 2KB + กฎวาง + seed | 1,118 ชิ้น × 33 แมพ |
| โล่เลือด | ไม่วาดเลย | noise + voronoi + 1 พารามิเตอร์ (ขนาดรู) | อนิเมชันทั้งชุด |
| ดาบ/เกราะ | ภาพ 1 ใบ + ชั้นแสงแยก | ฟังก์ชันความสว่างตามเวลา | ของที่ "มีชีวิต" |
| หมวก | หมวก 148 ใบ | offset 3 ตัวเลข/ใบ (หน่วยสัมพัทธ์) | ใส่ได้ทุกทรงผม |

ทุกครั้งที่จะทำอะไรใหม่ ถามตัวเองว่า: **"ส่วนไหนต้องวาด ส่วนไหนเป็นข้อมูลได้?"**

---

## หลักที่ 1 — แยกให้เกม "เข้าใจ" ไม่ใช่แค่ "เห็น"
- ภาพเดียวทั้งผืน = จุดสีหลายล้านจุด เกมไม่รู้อะไรคืออะไร (เดินทะลุบ้าน ทับยอดไม้ เดินบนน้ำ)
- แยกชิ้น + **ติดป้าย (tag)** ให้แต่ละชิ้น: ชน / บัง / ส่องแสง / ไหวตามลม / เดินผ่านได้
- **ต่อยอด:** ระบบไหนที่ต้อง "โต้ตอบ" ได้ ต้องแยกชิ้นเสมอ เช่น ของที่ทำลายได้ → แยกชิ้นแตก, หญ้าที่โดนฟันแล้วขาด, ประตูที่เปิดได้, NPC ที่หันตามผู้เล่น. ป้ายเดียวกันยังใช้กับ AI ศัตรู (หลบหลังต้นไม้ = tag "บัง"), เสียงฝีเท้า (tag พื้น), และระบบ minimap ได้ฟรี

## หลักที่ 2 — Hierarchy (พ่อ-ลูก) + Pivot ที่ถูกจุด
- หมุนพ่อ ลูกตาม: สะโพก → ลำตัว → แขน → มือ → อาวุธ
- Pivot ผิดจุด = ชิ้นหลุด. หาอัตโนมัติได้ด้วยสัดส่วน (ศอก≈45% ของแขน, เข่า≈47% ของขา)
- ลำดับวาด หลัง→หน้า (แขนหลัง, ขาหลัง, ขาหน้า, ลำตัว, อาวุธ, แขนหน้า, หัว)
- **ต่อยอด:** ใช้ได้กับทุกอย่างที่มีข้อต่อ — มอนสเตอร์ 4 ขา, มังกร (หาง = โซ่กระดูกยาว), รถถัง (ตัวรถ → ป้อม → ปืน), บอสหลายส่วน, ต้นไม้ไหวลม (ลำต้น → กิ่ง → ใบ), UI ที่เป็นกลไก. ของที่ติดตัวละคร (หมวก อาวุธ ปีก ออร่า) แค่ "เกาะ" กระดูกที่ถูกต้อง

## หลักที่ 3 — แม่แบบเดียว จุดยึดตรงกัน (Template / Anchor contract)
- ทุกชุดวาดบนแม่แบบเดียว จุดข้อต่อตรงกัน → เปลี่ยนชุดได้ทันทีทุกท่า
- หมวกใช้ offset เป็น **หน่วยสัมพัทธ์ (ความกว้างหัว)** ไม่ใช่ pixel → ใช้ได้ทุกขนาดหัว
- เครื่องมือแสดงผลกับ **ทุก variant พร้อมกัน** (หมวก × ทุกทรงผม) → เห็นปัญหาทันที
- **ต่อยอด:** ระบบ customization ทุกแบบ (สีผิว, หน้า, ปีก, สัตว์เลี้ยง, ยานพาหนะ), skin ของอาวุธ, ตัวละครหลายขนาด (เด็ก/ผู้ใหญ่ ใช้ rig เดียวกัน scale ต่างกัน). กฎ: **กำหนด "สัญญา" (anchor, ขนาด, มุม) ก่อนผลิต asset ชิ้นแรก**

## หลักที่ 4 — ท่าทาง = ตัวเลข, การเคลื่อนไหว = คีย์ + เส้นโค้ง
- ท่า = มุมกระดูก ~11 ค่า; อนิเมชัน = คีย์ไม่กี่ท่า + easing ระหว่างคีย์ (เกม interpolate เอง 60fps)
- **Easing คืออารมณ์:** linear = แข็ง/หุ่นยนต์, ease in-out = สบาย, ease-out แรง ("ระเบิด") = ทรงพลัง
- ผสมท่าได้เพราะกระดูกแยกกัน (ขาเดิน + แขนฟัน)
- จัดท่าภาพเดียว → เกมสร้าง ยืน/เดิน/วิ่ง/หายใจ ให้ (procedural)
- **ต่อยอด:** easing ใช้กับ **ทุกอย่างที่เคลื่อน** ไม่ใช่แค่ตัวละคร — UI popup, ตัวเลขดาเมจเด้ง, กล้องซูม, ไอเทมดรอป, หน้าต่างเปิด. ท่าที่เป็นตัวเลขยังทำ: random variation (ยืนไม่ซ้ำกัน), ท่าตามสถานะ (HP ต่ำ = โน้มตัวมากขึ้น), mirror/flip ฟรี

## หลักที่ 5 — Game feel: จังหวะ สำคัญกว่า ภาพ
- **ท่าโจมตี 4 จังหวะ:** ง้าง (ช้า ให้รู้ตัว) → ฟัน (เร็วสุด) → ตามแรง (ค้าง) → คืนท่า
- **เฟรมที่โดน:** ดาเมจ + เสียง + FX เกิด "พร้อมกัน" + หยุดภาพสั้นๆ (hitstop)
- คอมโบ 3 ท่า ท่าสุดท้ายแรงกว่า + จอสั่น (escalation)
- เดิน: แขนแกว่ง **สวน** ขา, หัวโยกตามก้าว, เข่างอตอนยกเท้า
- **ต่อยอด:** โครง "anticipation → action → follow-through → recovery" ใช้ได้กับ: ศัตรูเตือนก่อนโจมตี (ง้างนาน = ผู้เล่นหลบได้ = เกมแฟร์), สกิลบอส, การกระโดด, การยิงธนู, แม้แต่ UI ปุ่มกด. Hitstop ปรับความยาวตามความแรงของการโจมตี; คริติคอลยาวกว่า

## หลักที่ 6 — แยกชั้นแสงออกจากภาพ (Emissive layer)
- วาดภาพหลัก + **ชั้นแสงแยก** (vein: แดง→ส้ม→แกนเหลือง) + **ชั้น bloom** (เบลอ 2 ขนาด ล้นขอบ) → ซ้อนแบบ additive (lighter)
- พอแสงแยกชั้น → **ควบคุมด้วยโค้ดได้**: เต้นตามจังหวะหัวใจ (ตุบ-ตุบ-พัก), ฟันแล้วสว่างพุ่ง, ทุกชิ้นในเซ็ตเต้นจังหวะเดียวกัน
- Bloom เฉพาะสีสด ไม่ใช่ทุกสี (ไม่งั้นเป็นก้อนขาว)
- **ต่อยอด:** ไอเทมระดับหายาก (legendary เต้นเร็วกว่า), สถานะ (ติดพิษ = เส้นเขียวเต้น), HP ต่ำ = แสงกระพริบเร็ว, ชาร์จสกิล = ความสว่างค่อยๆ เพิ่ม, ดวงตาบอสเรืองก่อนโจมตี (บอกจังหวะ). ทุก "ข้อมูลเกม" กลายเป็นภาพได้ผ่านชั้นแสง

## หลักที่ 7 — ใช้ AI ให้ถูกงาน
| AI เก่ง | AI ไม่เก่ง (ต้องมีระบบคุม) |
|---|---|
| คอนเซ็ปต์ / ภาพอ้างอิง | ความสม่ำเสมอข้ามหลายภาพ (หน้า สี ขนาดเพี้ยน) |
| แตกชิ้นส่วนตามแม่แบบ | ภาพใหญ่ความละเอียดสูง (1.6M px vs ต้องการ 20.8M) |
| เจนหลายตัวเลือก (variants) ให้เลือก | ควบคุมจุดเดียว (ย้ายถนนเส้นเดียว = ลุ้นใหม่ทั้งผืน) |
| ภาพประกอบ/แผนที่โลก | ข้อมูลเชิงเกม (ชน/บัง) |

เทคนิคที่ใช้:
- **Prompt เป็นชั้นแบบศิลปินลงสี:** เงา → มิติ → สี → ลายผิว → ไฮไลต์ → แสงเรือง
- **ใช้ผลงานก่อนหน้าเป็นภาพอ้างอิง** (ดาบ → เกราะ ให้รอยแดงตรงกัน)
- **พื้นหลัง magenta** (สีที่ไม่มีในตัวละคร) → ตัดพื้นเป๊ะ
- **ล็อคกฎสไตล์:** เส้นขอบกรมท่าเข้ม · ลงสีแบน · มุม 3/4 · ขนาดเทียบตัวละคร
- **มนุษย์เกลาต่อ:** ภาพ AI ละเอียดเกิน → ย่อลงขนาดเกมกลายเป็นนอยส์. ต้องเก็บเส้นขอบหนา ลบลายยิบย่อยเป็นระนาบ ยกความสว่าง
- **ทดสอบที่ขนาดจริงในเกม** เสมอ ไม่ใช่ที่ขนาดเต็ม

## หลักที่ 8 — เจนหลายแบบ แล้วตัดสินใน "บริบทจริง"
- ทริคขาหน้า: เจน 4 แบบ เปลี่ยนแค่ทิศปลายเท้า → ลองในท่ายืน → ดู **ทั้งตัว** ไม่ใช่ดูแค่ขา → ให้คะแนนตามความรู้สึก ("ความมั่นใจ")
- ชิ้นที่อยู่ใกล้คนดูที่สุด (ขาหน้า) สายตาไปหยุดก่อน → เปลี่ยนชิ้นเดียว บุคลิกเปลี่ยนทั้งตัว
- **ต่อยอด:** หาก "ชิ้นที่มีผลมากที่สุด" ในทุกงาน แล้วทำ variant เฉพาะชิ้นนั้น — ทรงคิ้ว (อารมณ์หน้า), มุมหัว (ท่าทาง idle), ปลายผ้าคลุม, ไอคอนสกิล. วิธีคิด: **วัดด้วยความรู้สึกที่ต้องการ** (มั่นใจ/น่ากลัว/น่ารัก) ไม่ใช่ "สวยไหม"

## หลักที่ 9 — ซ่อนจุดอ่อนแทนการแก้ (Cheat smartly)
- ปลายข้อต่อวาดโค้งมน ซ่อนใต้ลำตัว
- กระโปรงคลุมหัวขา → รอยต่อสะโพกหายไป; เกม clip ชายตามจังหวะก้าว
- สีชายกระโปรงเนียนกับขา → พรางสายตา
- Mesh skinning ที่ข้อพับ แทนการตัด 2 ท่อน
- "หลบมุม ลอยต่อ ช่วยหลบสายตาได้"
- **ต่อยอด:** FX/ฝุ่นตอนลงพื้นบังเท้าที่ไม่แนบพื้น, motion blur / slash trail บังเฟรมที่ขาด, เงาใต้ตัวช่วยให้ตัวละครดู "ยืนบนพื้น" แม้ไม่ตรง, เปลี่ยนฉากตอนจอมืด/แฟลชขาว. ถามเสมอ: **"ผู้เล่นจะมองตรงไหน?"** แล้วลงแรงตรงนั้น

## หลักที่ 10 — Procedural: กฎ + seed = เนื้อหาไม่จำกัด
- ใบสั่ง (ข้อมูลระดับสูง ~2KB) + กฎ (ยอดไม้ห้ามบังถนน, กกขึ้นรอบบ่อ, โคมเรียงข้างทาง) + seed = แมพทั้งผืน < 1 วินาที
- คนวางเองเฉพาะจุดสำคัญ (landmark 11 ชิ้น) โค้ดเติมที่เหลือ (1,107 ชิ้น)
- กฎเกมเพลย์อยู่ในตัวสร้าง: มอนเกิดเฉพาะที่เดินได้, ไม่เกิดในแคมป์, วาร์ปจับคู่ไป-กลับ
- **ต่อยอด:** dungeon, ถ้ำ, เมือง, ดาว, การ drop ไอเทม, ชื่อ NPC, เควสต์ย่อย, กองทัพศัตรู, ลวดลายเกราะ (noise), รูปร่างก้อนเมฆ. seed ใช้ทำ daily challenge (ทุกคนได้แมพเดียวกันวันนั้น), sharing (ส่ง seed ให้เพื่อน), และ debug (reproduce บั๊ก)

## หลักที่ 11 — Shader / VFX แบบ "ดูวาดมือ แต่โค้ดวาด"
สูตรโล่เลือด = **ชุดตัวต่อ** ที่ประกอบใหม่ได้:
1. รูปทรง (sphere/โดม ตามมุมกล้อง)
2. ลาย (fbm noise → domain warp → sine)
3. **Posterize เป็น 5 สีแบน** ← เคล็ดที่ทำให้ดูการ์ตูน
4. Voronoi cells (เซลล์/ฟอง/เกล็ด/รอยแตก)
5. Dissolve + rim (เจาะรู ขอบไล่สี)
6. แยกชั้นหน้า/หลังตัวละคร
7. Bloom เฉพาะสีสด
8. **พารามิเตอร์หลักตัวเดียว** ขับทั้งอนิเมชัน (ขนาดรู 0 → 0.35)
9. Boil (เลื่อน noise นิดหน่อยทุกเฟรม) + **15 fps** = ฟีลอนิเมะ
10. Bake เป็น sprite sheet → เกมไม่ต้องคำนวณ

**ต่อยอด (สลับตัวต่อ):**
- โล่น้ำแข็ง = เปลี่ยนสีเป็นฟ้า-ขาว + voronoi เป็นผลึก + ไม่เจาะรู
- ลาวา/พื้นเดือด = ลาย noise บนระนาบ + posterize ส้ม-แดง + boil
- พอร์ทัล = วงแหวน + domain warp หมุน + dissolve ตรงกลาง
- เกราะแตก = voronoi + dissolve ทีละเซลล์
- ศัตรูตาย/วาร์ปหาย = dissolve + rim สีธาตุ
- พลังพิษ = voronoi + สีเขียวม่วง + bubble
- เลือกว่า **runtime** (ปรับได้สด) หรือ **bake** (เบา) ตามว่าต้องโต้ตอบไหม

**พิสูจน์แล้วใน [vfx/vfx_lab.html](../vfx/vfx_lab.html)** (เปิดในเบราว์เซอร์ เลื่อนดูทีละขั้น 1–8 ได้):
| ตัวต่อ | โล่เลือด | โล่น้ำแข็ง | พอร์ทัล |
|---|---|---|---|
| รูปทรง | โดม | โดม | วงรีบนพื้น (มุมกล้อง 20°) |
| ลาย | warp แรง + sine = หินอ่อน | warp อ่อน = ฝ้าเกล็ด | พิกัดเชิงขั้ว + หมุนวน |
| Voronoi | ฟอง → เจาะรู | **ผลึกเหลี่ยม** (สว่างต่างกันทีละเซลล์) | เศษรูนรอบวง |
| พารามิเตอร์หลัก | ขนาดรู | **ความแข็งแรง** (เซลล์แตกหลุดทีละชิ้นตาม id) | รัศมีประตู + ฝั่งตรงข้ามเป็นอวกาศ |
| หน้า/หลัง | ครึ่งทรงกลม | ครึ่งทรงกลม (หน้าโปร่ง) | ครึ่งไกล/ครึ่งใกล้ของวง |
| Bloom | ขอบรู | **เฉพาะขอบผลึก + rim** | ขอบประตู + ดาว |
บทเรียนจากการลองทำ: ครั้งแรกตั้ง bloom ให้โทนสว่างของน้ำแข็ง → กลายเป็นก้อนขาวทั้งลูก (พลาดแบบเดียวกับสีครีมในคลิป). **bloom ต้องเลือกเฉพาะ "เส้น/ขอบ" ไม่ใช่ "พื้นที่" ที่สว่าง**

## หลักที่ 12 — แสง 2D ด้วย Normal map + post stack
- Shader แสง: `color = art × (ambient + sunColor × dot(normal, sunDir) + nearbyLamps)`
- ภาพ 2D แบนไม่รู้ทิศผิว → **normal map** (สีบอกทิศ) สร้างอัตโนมัติจากภาพ: ความหนาจากขอบ + เส้นแบ่งส่วน
- **ลำดับชั้น post:** ภาพ → แสงแดด+normal → เงา → ไฟ+ของเรืองแสง → bloom → หมอก+ลำแสง → color grade ตามเวลา → vignette → DOF (tilt-shift)
- วงจรวัน: เช้า (ชมพูส้ม เงายาว) → เที่ยง (สด เงาสั้น น้ำระยิบ) → เย็น (ทอง หมอก ลำแสง) → กลางคืน (ของเรืองแสงกลายเป็นแหล่งไฟจริง)
- **งบ performance:** 4.5ms จาก 16.7ms (60fps); ทุกชั้นปิดได้ตามเครื่อง
- **ต่อยอด:** ถ้ำมืดที่ผู้เล่นถือคบเพลิง (light = เกมเพลย์), สภาพอากาศ (ฝน = ลดแสงแดด + เพิ่มหมอก), อารมณ์ฉาก (บอสโผล่ = color grade แดง), stealth (เงา = ซ่อนได้). DOF โฟกัสตามตัวละคร = สายตาอยู่ที่การเล่น

## หลักที่ 13 — สร้างเครื่องมือของตัวเอง (Tooling)
ทุกระบบในคลิปมีเครื่องมือเฉพาะ: Pose Studio, Hat editor, rigcut.py, debug panel เปิด FX ทีละชั้น, ตัวสร้างแมพ
ลักษณะร่วมของเครื่องมือที่ดี:
- **ใช้โค้ดเดียวกับเกม** (เห็นอะไร = ได้อย่างนั้น)
- Preview **ขนาดจริงในเกม** + **ทุก variant พร้อมกัน**
- ค่าเป็น slider + ตัวเลข + ปุ่ม nudge + คีย์ลัด (ลูกศร, Shift ทีละมาก, [ ] ถัดไป, Ctrl+Z/S)
- สถานะ: แก้แล้วยังไม่บันทึก / บันทึกแล้ว; ย้อน / กลับค่าที่บันทึก / ค่าเริ่มต้นของเกม
- **Toggle ทีละชั้น** เพื่อดูว่าแต่ละอย่างเพิ่มอะไร
- กดบันทึก → เข้าเกมทันที (ไม่มีขั้นตอน export)
- **ต่อยอด:** ทุกครั้งที่ต้องปรับค่าซ้ำเกิน ~10 ครั้ง → ทำเครื่องมือ. (เช่น editor สกิล FX, editor ตำแหน่ง hitbox, editor คอมโบ, editor ใบสั่งแมพ)

## หลักที่ 15 — ความมันส์ของสกิล = Feedback ซ้อนชั้น (จากคลิป c8)
- **ตัวเลขคือรางวัล**: ดาเมจเด้งทุกฮิต + **TOTAL สรุปคอมโบ** ตัวใหญ่ = ผู้เล่นรู้สึกว่าโตขึ้น โดยไม่ต้องวาดอะไรเพิ่ม (ข้อมูลล้วน)
- **Impact frame** 1–3 เฟรม (จอสีเรียบ + ศัตรูเป็นเงาดำ) ใช้เฉพาะท่าใหญ่ → ให้น้ำหนักแบบไม่เปลือง asset (แค่ shader สลับสี)
- **สีประจำอาชีพ** ล็อกทั้งชุดสกิล: ทำ VFX ชุดเดียว แล้ว tint สีต่อสาย = ได้หลายอาชีพจากของชุดเดียว (ตรงกับปรัชญา "วาดน้อย ข้อมูลขยาย")
- คูลดาวน์สั้น + AOE กว้าง + มอนฝูงแน่น = จังหวะ "กวาดล้าง" ที่ต้องมีตัวเลขเยอะมาเป็นตัวบอก

## หลักที่ 16 — แมพ/มอน/สกิล ผูกกันเป็นธีมเดียว
- แมพมืด+ธีมแดง vs แมพทะเลสาบ+ธีมเขียว: **พื้นหลังโทนตรงข้ามกับสีสกิล** ทำให้เอฟเฟกต์เด่น
- มอนแต่ละแมพ = ชื่อ+Lv ช่วงแคบ (เช่น 85–95) → spawn table ต่อแมพ เป็นข้อมูล ไม่ใช่โค้ด
- **ต่อยอดกับเกมเรา:**
  - แมพ: เพิ่ม field `palette` + `levelRange` + `spawnTable` ในใบสั่งแมพ; เลือกสีพื้นให้ตัดกับสีสกิลหลักของอาชีพที่มาฟาร์ม
  - มอน: 1 sprite + `tint`/`scale`/`stats` → หลายสายพันธุ์; spawn เป็นฝูง (cluster) ให้ AOE มีที่ลง
  - สกิล: นิยามเป็น data `{shape: arc|ring|dash|orb, radius, hits, interval, element, color}` + VFX base ไม่กี่แบบ + tint
  - ระบบ feedback: damage number pool (object pooling), combo TOTAL หลังหยุดตี ~0.8s, impact frame flag ต่อสกิล, hit-stop 40–80ms
  - HUD: hotbar พร้อมตัวเลข CD, AUTO mode, log EXP — ทำครั้งเดียวใช้ทุกแมพ

## Reference จากเกมอื่น (Hunter Raid)
- ตัวเลขดาเมจใหญ่แบบ idle (1.71E, 8.46E) ซ้อนกันเป็นกอง = ความรู้สึก "แรง"
- HUD: HP/MP ซ้ายบน, boss bar % กลางบน, skill hex 6 ช่อง + cooldown ตัวเลข + แท็บชุดสกิล
- FX สกิลเต็มจอ วงแหวนพลังซ้อน, ปุ่มเร่ง 2x
