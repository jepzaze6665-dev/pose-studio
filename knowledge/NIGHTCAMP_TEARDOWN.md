## 1. RIG ตัวละคร — 2 ยุคอยู่ด้วยกัน
**ยุคเก่า (cut-out ของเขาเอง, `anim.js` + `poselib`)**
- ท่า = ชุดตัวเลขช่องเดียวกันทุกท่า: x,y,rot, lean, head, breathe, sq(squash), aF/eF (ต้นแขน/ศอกหน้า), aB/eB, legF/kF, legB/kB, wAng/wPush/wLen (อาวุธ), wHide/wSheath/wFar (ซ่อน/เก็บฝัก/ถือมือหลัง), turn, hx…
- คลิปจาก Pose Studio: `kind` (attack/loop/shot), `dur`, `hit` (วินาทีที่ดาเมจลง), `lunge` (พุ่งไปหน้ากี่ px), `aim` (หันตามเป้า), keys[t, curve, P]
- **ท่าค้างภาพเดียว (shot)** เกมเติมชีวิตให้เอง: หายใจ, หัวโยกช้ากว่าตัวครึ่งจังหวะ, น้ำหนักโยก, แขน+อาวุธขึ้นลงเบาๆ
- **กฎ aim ในท่าตี** (สำคัญมาก): เพิ่มมุมเป้าทั้งหมดเฉพาะจังหวะฟัน (AS), จังหวะง้าง/ตามแรงเพิ่มแค่บางส่วน (AW), แขนห้ามยกจนกำปั้นทับหน้า chibi (AU/UP), อาวุธยาวห้ามจมดินเกิน ~18px, เล็งขึ้นแล้วเอนตัวหลังนิดหน่อย (LU)
- อาวุธแบ่ง "ตระกูลการถือ" (ดาบ, ดาบใหญ่, ขวาน/ค้อน, หอก/ไม้เท้า, ธนู…) → อาวุธใหม่ 1,251 ชิ้นแค่บอกว่าอยู่ตระกูลไหน
- `rigparts`: เลือกชิ้นต่อชุดได้ เช่น `legF` = v2 ตอนเดิน, `legF_idle` = v3 ตอนยืน (ทริคขาหน้าคลิป c4 ทำเป็นข้อมูลจริง)

**ยุคใหม่ (Spine, `herospine`) — ตัวเอกหลักตอนนี้**

- กระดูก 35: root→cha→hip→body_1→body_2→head; แขน 3 ท่อน+มือ; ขา 3 ท่อน+เท้า; ผม 3 เส้น (T/B/F); ผ้าพันคอ 3 ข้อ; sword, nock(สายธนู), fx

- slot 16 ชั้น ลำดับหลัง→หน้า: scarf, อาวุธหลัง, แขนหลัง, ขาหลัง, ขาหน้า, ลำตัว, ดาบหลัง, สายธนู, fx, หัว, หน้า, ดาบ, ต้นแขนหน้า, ดาบหน้า, กำปั้น, แขนล่างหน้า
  → **แขนหน้าแยก 3 slot** ให้ดาบแทรกระหว่างต้นแขนกับกำปั้นได้ (ดาบอยู่ในมือจริง)
- ชิ้นเป็น **mesh** (ขาหน้า: 360 จุด uv, 306 สามเหลี่ยม) → งอเข่า/ศอกแบบไม่แตก
- หน้า 2 ภาพ: face / face_blink (กระพริบตา)
- คลิป 164 ท่า = **อาวุธ 22 ประเภท × (idle, walk, run, atk1–3)** + ท่าชีวิต (ตกปลา 6 ท่า, ขุด, ฟัน, รดน้ำ, คุกเข่า, นั่ง/ลุก) + วิ่ง 8 แบบให้เลือก
- คลิปเก็บเป็น timeline ต่อกระดูก: rotate/translate @30fps; วิ่ง 1 รอบ = 0.33 วิ เล่นที่ความเร็วเกม 310 px/s
- ทุกท่าตีมี metadata: `hit` (เฟรมดาเมจ), `muzzle` (ปืนยิงจากปลายไหน), `wind` (ช่วงง้าง) → เกมต่อดาเมจ/เสียง/เอฟเฟคตรงเฟรม

- `spinekit`: อ่าน Spine 3.7 แล้ว **retarget** ท่าจากชุดท่าสำเร็จรูปมาใส่ rig ตัวเอง (ปรับสเกลจากความสูงสะโพก)
- `meshrig` (**auto rig**): ภาพเดียวไม่ต้องตัด → วาง grid mesh บนส่วนที่มีสี → น้ำหนักกระดูกจาก "ระยะเดินบนเนื้อภาพ" (geodesic, Dijkstra) 3 กระดูกใกล้สุด → ใช้กับบอส/มอน (baph, pet)

## 2. แมพ
- `maps.js`: แบบ MMO คลาสสิก — แคมป์ตรงกลาง ทุ่งล่ารอบๆ เชื่อมด้วย warp; เก็บแมพที่สร้างแล้วไว้ไม่กี่อัน (สลับกลับทันที)
- `fieldgen.js` สร้างทุ่งจาก "คำบรรยาย": biome (ทุ่งหญ้า / ป่าเห็ดเรือง / หุบผาแดง), ถนน, บ่อ, ที่ราบสูง, แปลงนา/แถวหลุมศพ, zone (เลเวลมอน, `decor` = สัดส่วนของตกแต่ง)
- ของในทุ่งหญ้า 14 ภาพ (เบิร์ช, แอปเปิล, กระท่อม, กังหันลม, กองฟาง, บ่อน้ำ, หญ้า, ดอกไม้, พุ่มไม้, หิน, รั้ว) จุดยึดที่เท้า (ay=1) ขนาดเป็นหน่วยโลก
- ของทุกชิ้นมี **kind**: tree | house | tall | rock | bush | post | fence | low → ใช้ตัดสิน ชน, เงา, ยอดไม้จางเมื่อผู้เล่นเดินหลัง, และกล่องชนของบ้าน `rect`, แสง `light`
- **การชนแยกตามผู้ชน**: ผู้เล่นเดินอ้อม, กระสุนบินผ่านต้นไม้/หิน/รั้วได้แต่ไม่ผ่านน้ำ/หน้าผา/บ้าน, มอนไม่สนของตกแต่ง, ท่าพุ่งข้ามของเตี้ยได้
- **พื้นวาดด้วยโค้ด 2 รอบ (กลางคืน + กลางวัน) แล้วเฟดผสม**: ถนน = วงกลมซ้อนตามเส้นโค้ง (ขอบโยก), บ่อ = ทราย→น้ำ→กลางลึก→ระลอก→ใบบัว, หน้าผามีลายชั้นหิน
- กฎวาง: ยอดไม้ (ซึ่งบังพื้นทางเหนือลำต้น) ห้ามคลุมถนน/warp; หญ้าบางกลางแคมป์ หนาขึ้นไปทางป่า; มอนวางห่างจุดเกิด ≥520
- minimap สร้างจากข้อมูลเดียวกัน (1px = 10 หน่วย)
- `daynight.js` + `lightkit` (เอฟเฟคสกิลจากแสง มี exposure อัตโนมัติ: ของเรืองยิ่งเยอะ แต่ละชิ้นยิ่งหรี่ จอไม่ขาวโพลน)

## 4. ของตกแต่งหัว: หมวก · ผม · แว่น (แกะเพิ่ม)
**ผม = ส่วนหนึ่งของหัว**
- หัวจากหน้าสร้างตัว = ภาพหัว (ผมหน้า+บน) + **ผมหลังแยกชั้น** วาดหลังลำตัว (ผมยาว หางม้า) หมุนตามหัว
- สีผม/ชุดใช้ระบบย้อม (dye) เปลี่ยนสีภาพ ไม่ต้องวาดใหม่ · ทรงผมพรีเมียมมีประกายรอบหัว
- ทุกทรงผมวัดค่า "ขนาดหัว" อัตโนมัติ: ระยะยอดผมเหนือแนวตา, แนวตา, กลางตา (หน่วย = ความกว้างหัว)

**หมวก — 3 ชั้นข้อมูล (ทับกันตามลำดับ)**
1. วัดอัตโนมัติจากสคริปต์ตัดภาพ (บนหัวทดสอบสีเขียว): `fit` ขนาด, `seat` จมลงหัวแค่ไหน, `clip` ตัดผมใต้หมวกไหม, `brim` แนวขอบหมวก
2. จัดมือในหน้าจัดหมวก (ต่อใบ): `dx, seat, fit, clip` — ~84 ใบ
3. **คู่หมวก × ทรงผม** (เฉพาะคู่ที่มีปัญหา): `dx, seat, fit, rot, clip, trim`, `hideBack` ซ่อนผมหลัง
- ถ้าคู่ไหนไม่ได้จัด → เอาค่าของใบนั้นมา "ปรับตามขนาดหัว" (สเกลรอบแนวตา ตามแค่บางส่วน เพราะหน้าขนาดเท่าเดิม)
- หมวกที่วัดอัตโนมัติมักลอย (จม 0.02–0.24) ส่วนที่จัดมือจม 0.33–0.54 (ขอบถึงคิ้ว) → เกมดึงหมวกที่ไม่ได้จัดลงมาเอง
- หน่วยทั้งหมด = ความกว้างหัว → ใช้ได้ทุกขนาดหัว

**การวาดหมวกบนหัว**
- `clip`: ลบผมเหนือแนวขอบหมวก (ขยับด้วย `trim`) → ผมไม่ทะลุหมวก
- ลำดับ: หัว (ผมใต้หมวกถูกตัด) → ตัวหมวก → ขอบหมวก
- มงกุฎดอกไม้ (`back`): ครึ่งหลังวาดหลังหัว · ฮู้ด (`rimBehind`/`hood`): คลุมบน ส่วนข้าง/หลังห้อยหลังหัว หน้าอยู่หน้าฮู้ด
- **หมวกมีสปริง**: หน่วงตามการหันหัว, เอียงหลังตอนออกตัว เอียงหน้าตอนหยุด, ยุบตอนลงพื้น — ไม่เกินไม่กี่องศา (ไม่ใช่แกว่งเอง)
- เอฟเฟคหมวกแพง (ภาพล้วน): aura, จุดเรืองเต้น, อนุภาค (ถ่านไฟ สปอร์ หิมะ ฟอง…), ประกาย, คริสตัลหมุนรอบหัว, สายฟ้า, หิ่งห้อย, แถบเงาวาววิ่งผ่าน, หมวกตะเกียงส่องแสงรอบตัวตอนกลางคืน

**แว่น** = slot แยก · หัวแต่ละแบบเก็บตำแหน่งตาใกล้/ไกล (สัดส่วนภาพ) · แว่นวางตามตา ไม่ใช่ตามหัว

**เครื่องประดับ** 2 ช่อง (acc1/acc2) แบบ RO · ผ้าคลุม/หาง/ไฟจิ้งจอก ผูกกับกระดูกสะโพก/ไหล่
