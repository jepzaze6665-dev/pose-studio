> คลิปสอนแค่สไลม์ แต่สูตรเป็นแบบทั่วไป: **ภาพ AI 1 ใบ → ตัดชิ้น → mesh → กระดูก → physics → ท่า 5 ท่า**
> ตัวเลขสไลม์ในคลิป: **14 ชิ้น · mesh 621 จุด · กระดูก 23 · physics 4 · 5 ท่า** (idle · hop · attack · hit · die)
> ดูหลักใหญ่ใน [PRINCIPLES.md](PRINCIPLES.md) — ไฟล์นี้คือภาคปฏิบัติสำหรับ "มอน"

## 0. ทำไมต้องริก (ก่อนริก vs หลังริก)

| | ภาพเดียว (ก่อนริก) | ริกแล้ว (หลังริก) |
|---|---|---|
| idle | ยืด-หดทั้งใบ | หายใจ + กะพริบตา + กลอกตา + ฟองลอย |
| hit | กะพริบขาว | หลับตา ตัวบี้ แล้วเด้งกลับ |
| attack | กระโดดแบบเดิม | ตาโกรธ พุ่งชน |
| die | หายวับ | ละลายเป็นแอ่งน้ำ |
| spawn | โผล่มาเฉยๆ | ภาพเหมือนกันเป๊ะ แต่ "มีชีวิต" ขึ้นเยอะ |

บทเรียน: **ภาพสวยเท่าเดิม สิ่งที่เพิ่มคือ "ส่วนเล็กๆ ขยับเอง"** — ตา, ปลาย, ของประดับ คือสิ่งที่ทำให้มีชีวิต ไม่ใช่ตัวหลัก

## 1. ขั้นตอน 6 ขั้น (สูตรกลาง)

### ① ภาพต้นฉบับ
- ให้ AI วาดมอน 1 ใบ **ภาพเดียวกับที่ใช้ในเกม** (สไตล์ล็อกตาม skill game-art-pipeline)
- ชี้ส่วนที่อยากให้ "ขยับเองได้" ก่อนตัด — สไลม์: ปลายหยดน้ำ, ใบบัว, หน้า+ตา, ตัวเจลลี่, ฟองอากาศ
- กฎ: **อยากให้ส่วนไหนขยับเองได้ → ต้องแยกเป็นชิ้น**

### ② ตัดชิ้น
- ยกชิ้นออก → ข้างใต้จะเป็น "รู" → **ต้องวาดเนื้อเติมใต้ชิ้น** (ใต้หน้า ใต้ใบบัว ใต้ฟอง) ไม่งั้นขยับแล้วเห็นรู
- ส่วนที่เปลี่ยน "รูปร่าง" ไม่ใช่ "ตำแหน่ง" ให้วาดหลายแบบแล้วสลับ (sprite swap): ตาวาด 3 แบบ = ลืมตา · หลับตา · โกรธ
- สไลม์ได้ 14 ชิ้น: ตัวเจลลี่ 1, หน้า 1, ตา 1 (3 แบบ), ใบบัว 1, ฟองอากาศ 10

### ③ Mesh (ตาข่าย)
- เฉพาะชิ้นที่ "นิ่ม/ยืดได้" ถึงทำ mesh (สไลม์: ตัวเจลลี่ 621 จุด) — ชิ้นแข็ง (ตา ฟอง) ไม่ต้อง
- กระดูกจะดึงจุดบนตาข่าย → ภาพยุบ-เด้งได้โดยไม่ต้องวาดใหม่
- ตาข่ายหนาแน่นตรงที่งอมาก (ปลายหยด ขอบล่าง) โปร่งตรงกลาง

### ④ กระดูก — วางทีละ "กลุ่ม" แต่ละกลุ่มคุมคนละส่วน
| กลุ่ม (สไลม์) | จำนวน | หน้าที่ |
|---|---|---|
| ตัวหลัก | 3 | ราก · กระโดด · ยุบยืด (ทั้งตัว) |
| กรงเจลลี่ | 5 | ฐาน กลาง โดม สองข้าง (ดัดรูปทรง) |
| ปลายหยดน้ำ | 2 | โซ่ปลาย |
| หน้า+ตา | 2 | หน้าเลื่อน, ตามอง |
| ใบบัว | 1 | |
| ฟองอากาศ | 10 | ลอยทีละเม็ด |
| **รวม** | **23** | |

หลักการแบ่งกลุ่ม → ใช้ได้กับทุกมอน:
1. **ราก/ตัวหลัก** (ย้ายทั้งตัว + squash/stretch)
2. **กรงรูปทรง** (ดัดลำตัว — เฉพาะตัวนิ่ม)
3. **โซ่ปลาย** (หาง หู หนวด ปีก ผม — ส่วนที่ physics จะดูแล)
4. **หน้า/ตา** (อารมณ์)
5. **ของประดับ** (ใบไม้ เขา เครื่องประดับ)
6. **อนุภาคติดตัว** (ฟอง ไฟ วิญญาณ ประกาย)

### ⑤ Physics (สปริงตามหลัง)
- ไม่มี physics = ทุกอย่างขยับตามคีย์เป๊ะๆ (แข็ง)
- มี physics 4 ตัว (ปลาย, ใบบัว, โดม, สาย) = **ส่วนปลายดีดตามเองหลังเด้ง ช้ากว่านิดนึง**
- ใส่ physics เฉพาะ "ปลายโซ่" — ไม่ใส่ที่ราก (จะเละ)
- โค้ดจริงแค่ spring-damper ต่อกระดูก: `v += (target-angle)*k - v*damp; angle += v`

### ⑥ ทำท่า 5 ท่า จากกระดูกชุดเดียว
idle · hop/move · attack · hit · die (+ spawn/ฟื้นกลับ = die เล่นย้อน)
- **ท่า = ตัวเลขมุม/ตำแหน่งกระดูก** ไม่ใช่ภาพใหม่ → มอนตัวใหม่ทำท่าได้ทันทีถ้าโครงกระดูกชื่อเหมือนกัน

## 2. ขยายไปมอนสายพันธุ์อื่น — "Archetype" 6 แบบ

ไม่ต้องคิดทีละตัว: มอนเกือบทุกตัวตกอยู่ใน 6 โครงนี้ ทำโครง 1 ครั้ง ใช้ซ้ำได้ทั้งตระกูล (สลับสกิน = เปลี่ยนชิ้นภาพ)

### A. ก้อนนิ่ม (Blob) — สไลม์, เห็ด, เยลลี่, ก้อนโคลน, mimic
- = สูตรในคลิปเป๊ะ · mesh หลัก + กรง 5 · ปลาย 2 · ของประดับ
- ต่อยอด: สไลม์ไฟ (ฟอง→ประกายไฟ, die=ดับเป็นควัน), สไลม์พิษ (die=แอ่งพิษเหลือค้าง)

### B. สี่ขา (Quadruped) — หมาป่า, หมี, หมูป่า, เสือ, กวาง
| ชิ้น | หมาป่า | หมี |
|---|---|---|
| ลำตัว (mesh เบาๆ ให้หายใจ) | 1 | 1 (อ้วน → squash มาก) |
| หัว + ขากรรไกรล่างแยก | 2 | 2 |
| ตา (3 แบบ) / หู ×2 | 1+2 | 1+2 (หูเล็ก ไม่ต้อง physics) |
| ขา ×4 (บน/ล่าง = 8) | 8 | 8 (หนา สั้น) |
| หาง (โซ่ 3–4 กระดูก) | 1 | 1 (สั้น 1 กระดูก) |
| ขนคอ/แผงคอ (ชั้นหน้า) | 1 | — |
- กระดูก ~20–24: ราก, สันหลัง 2–3, คอ, หัว, กราม, หู 2, ขา 4×2, หาง 3–4
- physics: หาง, หู, แผงคอ, (หมี: พุงหย่อน = กระดูก physics 1 ตัวใน mesh)
- ท่า: idle(หายใจ หูกระดิก) · move(วิ่ง 4 จังหวะ: ขาหน้า-หลังสลับ) · attack(ย่อ → กระโจนกัด, หมี = ยืนสองขา → ตบ) · hit(สะบัดหัว ตาหลับ) · die(ล้มตะแคง)
- **เคล็ด: 4 ขาใช้ walk cycle เดียว** ขาหลังเลื่อนเฟส 0.5 จากขาหน้า

### C. มีปีก (Winged) — มังกร, ค้างคาว, นก, wyvern, แมลง
- ชิ้นเพิ่ม: ปีก ×2 แยก "แขนปีก" + "พังผืด" (พังผืด = mesh ผูกกับกระดูกนิ้ว 3 อัน → กางหุบได้)
- คอยาว + หางยาว = โซ่ 4–6 กระดูก (มังกร) · เขา/หนาม = ของประดับแข็ง
- physics: ปลายหาง, ปลายคอ (เบา), ปลายพังผืด, หนวด
- ท่า: idle(ลอย = ราก sin ขึ้นลง + ปีกกระพือ, หรือยืนหายใจ ปีกหุบ) · attack(ง้างคอไปหลัง → พ่นไฟ = VFX ยิงจากกระดูก "ปาก") · hit · die(ร่วงลงพื้น ปีกพับ)
- **มังกรตัวใหญ่ (บอส)**: เพิ่ม "ท้อง/คอเรืองแสง" ชั้น glow ก่อนพ่นไฟ (ใช้ระบบ glow ของ rig.js)

### D. สองขาคล้ายคน (Humanoid) — ปีศาจ, ก็อบลิน, ออร์ค, โครงกระดูก, ซอมบี้
- **ใช้ rig ฮีโร่ที่มีอยู่แล้ว** (`engine/rig.js`) + เพิ่มกระดูก: เขา, หาง (โซ่), ปีก (ถ้ามี), เสื้อคลุมขาด (physics)
- ปีศาจ: หางปลายแหลมโซ่ 4 + ปีกเล็ก + ตาเรืองแสง (glow) · โครงกระดูก: die = **ชิ้นกระจาย** (ปล่อยทุกชิ้นให้ตกเองด้วย gravity — ได้ฟรีเพราะแยกชิ้นอยู่แล้ว)
- ท่า attack ยืมจาก ATK ของฮีโร่ได้เลย

### E. ลอยไร้ขา (Floater) — ผี, วิญญาณ, ภูตไฟ, ตาลอย, แมงกะพรุน
- ลำตัว mesh + **ชายล่างเป็นโซ่ physics 3–5 เส้น** (ชายผ้าผี / หนวดแมงกะพรุน)
- ไม่มี "พื้น" → เงาจาง, ลอยขึ้นลงตลอด
- ใช้ alpha/blend เป็นส่วนของท่า: hit = ใสขึ้น, die = จางหาย + อนุภาคลอยขึ้น, spawn = ค่อยๆ ทึบ
- เคล็ด: ผีหลับตา/ตาว่างเปล่า = sprite ตา 3 แบบเหมือนสไลม์

### F. หลายส่วน/งู (Segmented) — งู, หนอน, ตะขาบ, มังกรจีน
- ลำตัว = ชิ้นซ้ำ N ชิ้น (ปล้อง) แต่ละปล้องตามปล้องหน้าแบบ "follow the leader" (เก็บตำแหน่งหัวย้อนหลัง)
- วาดแค่ หัว + ปล้อง 1 แบบ + หาง → ยาวเท่าไรก็ได้

## 3. Checklist ก่อนส่งภาพให้ AI เจน (สำหรับมอนใหม่ทุกตัว)

1. เลือก archetype (A–F) → รู้ทันทีว่าต้องแยกชิ้นอะไร
2. ขอภาพ **"ตัวเต็ม"** 1 ใบ (ใช้ในเกม/ไอคอน) + **ชีทชิ้นส่วน** พื้นชมพูตาม pipeline เดิม
3. ในชีทชิ้นส่วน ต้องขอ:
   - ชิ้นที่ขยับเอง แยกทีละชิ้น
   - **ลำตัวแบบ "ไม่มีชิ้นบน"** (เนื้อเติมใต้หน้า/ใต้ประดับ) — นี่คือจุดที่ลืมบ่อยที่สุด
   - ตา 3 แบบ: ปกติ · หลับ/เจ็บ · โกรธ (+ ปากอ้า/หุบ ถ้ามีปาก)
4. ด้านข้างหันขวาเสมอ (กลับด้านด้วย scale −1)
5. แสงมาจากทิศเดียวกับชุดตัวละครเดิม

### Prompt แม่แบบ (ชีทชิ้นส่วน)
```
2D game monster parts sheet, [ชื่อมอน], side view facing right, same art style as reference,
thick dark outline, soft cel shading, flat pink #FF00FF background, each part separated with space:
full body (complete), body WITHOUT [หน้า/ประดับ] (fill the area underneath),
eyes x3 (open, closed, angry), [หาง/หู/ปีก/ขา แยกทีละชิ้น], [ของประดับ]
```

## 5. ต่อยอดกับเครื่องมือในโปรเจกต์นี้

- `engine/rig.js` ตอนนี้เป็น **rigid bone** (ชิ้นแข็งหมุนตามกระดูก) — พอสำหรับ archetype B, C, D, F
- ที่ยังขาดสำหรับ A, E (และพังผืดปีก):
  1. **mesh deform** — วาดชิ้นเป็นตาข่ายสามเหลี่ยม (canvas `drawImage` ทีละสามเหลี่ยม หรือ WebGL) แล้วให้จุดถ่วงน้ำหนักตามกระดูก
  2. **spring bone** — ชั้น physics หลัง sample ท่า: ปรับมุมกระดูกปลายโซ่ด้วย spring-damper
  3. **sprite swap** — ช่อง `eye: 'open'|'closed'|'angry'` ในคีย์ท่า (เหมือน `visor` ของฮีโร่)
  4. **ท่าใช้ร่วมตามชื่อกระดูก** — ตั้งชื่อกระดูกมาตรฐานต่อ archetype (เช่น quad: `root spine1 spine2 neck head jaw earL earR legFL_u ...`) ท่าเดียวใช้ได้ทั้งหมาป่า/หมี/เสือ
- ลำดับที่แนะนำ: spring bone (ง่ายสุด ได้ผลเยอะสุด) → sprite swap ตา → mesh deform → สร้าง monster_lab.html
