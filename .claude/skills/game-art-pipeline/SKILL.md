# Game Art Pipeline (สอน AI)

ปรัชญาเดียว: **วาดของน้อยชิ้นครั้งเดียว แล้วให้ข้อมูล + กฎ + โค้ดขยายผล** — ทุกงานใหม่ถามก่อนว่า "ส่วนไหนต้องวาด ส่วนไหนเป็นข้อมูลได้?"
หลักการเต็มอยู่ที่ `knowledge/PRINCIPLES.md` (หลัก 1–16) · prompt ทั้งหมดอยู่ที่ `PROMPT_PACK.md` · โครงโฟลเดอร์ที่ `README.md`
อย่าคัดลอกเนื้อหาจากไฟล์เหล่านั้นมาไว้ที่นี่ — ไฟล์นี้คือ "วิธีทำงาน + กับดักที่เคยเจอ"

## 1. ล็อกสไตล์ก่อนเสมอ
- บล็อก **STYLE LOCK v2** อยู่ที่ `PROMPT_PACK.md` §2 · แมพใช้ **TOWN STYLE LOCK** §4.6 — แก้ที่เดียว ห้ามแก้ทีละ prompt
- ภาพอ้างอิง (สำคัญกว่าตัวหนังสือ): `assets/style/char_anchor.png`, `town_anchor.png`, `town_overview.png` — บอกผู้ใช้ให้แนบทุก prompt
- ลำดับหาสไตล์: S1 เทียบหลายสไตล์ในชีทเดียว → S2 ทดสอบในฉากจริง (Map Lab `?hero=<โฟลเดอร์>`) → S3 ครอบครัว ฮีโร่+NPC+มอน → ล็อก (§4.7)
- ตัดสินสไตล์ใน "บริบทจริง" เสมอ (หลัก 8) — วางในเมืองแล้วดูเส้น/เงา/สเกล (ประตูสูงเท่าตัวละคร)

## 2. เขียน prompt ให้เจนแล้วใช้ได้จริง
- ชีทกริดตายตัว (เช่น 3x3) + **ร่องชมพู #FF00FF คั่น** + "each item separate with wide gaps" → ตัดอัตโนมัติได้
- หลายแบบใน prompt เดียวได้ ถ้าบังคับ "independent / same size / magenta gutters" (เคยได้หญ้า+ถนนปนกันเพราะไม่มีร่องคั่น)
- บอกขนาดที่อ่านออก ("6–8 stones across") ไม่งั้นได้ลายจุดเล็กๆ
- ของที่ต้องลอย/เรืองแยกเจนเป็นชิ้นของมันเอง (คริสตัล) · หน้าต่าง/โคมวาด "UNLIT" แล้วทำไฟด้วยโค้ด
- VFX sprite: กริดตายตัว + จุดยึดเดียวกันทุกเฟรม + เล่าเฟรมทีละจังหวะ ง้าง→ปะทุ→ค้าง→สลาย (§4.5)

## 3. รับภาพใหม่จากผู้ใช้ (ขั้นตอนมาตรฐาน)
ผู้ใช้วางไฟล์ `image-*.png` ไว้ที่ราก repo แล้วบอกว่า "เพิ่มให้แล้ว"
1. `git status --short | grep '^??'` หาไฟล์ใหม่ → ทำภาพรวมเลขกำกับ (PIL ต่อเป็น grid) แล้ว Read ดูทีเดียว
2. ระบุว่าแต่ละภาพคือชีทไหน แล้ว **ย้ายทีละไฟล์ด้วยคำสั่งแยกกัน** และ `ls` ยืนยัน — ห้าม mv ไปปลายทางเดียวกันสองครั้ง (เคยเขียนทับภาพรวม M1 จนหาย; ไฟล์ untracked กู้ไม่ได้)
3. ตัด: `python tools/cut_parts.py <sheet> <out>` (พื้นชมพู) · `cut_black.py` (VFX พื้นดำ) · `cut_grid.py` (sprite sheet)
4. เมือง: `python tools/build_town_kit.py` ตั้งชื่อชิ้นตามลำดับแถว→ซ้ายขวา, รวม decal ตามช่องกริด, ทำพื้นต่อกันได้ (ลาน `plaza` ไม่ทำ seamless — เป็นลายชิ้นเดียว)
5. ชั้นเสริม (รันเฉพาะไฟล์วัตถุ ห้าม glob `*.png` — จะได้ `_n_n`, normal ของ decal/พื้น):
   `make_normal.py <obj.png...>` · `make_night.py <อาคาร/โคม>` · `make_glow.py <in> <out_glow> blue|red|purple`
6. เปลี่ยนเลข `?kit=vN` ใน map_lab (ตัว `load()`) — เบราว์เซอร์แคชภาพชื่อเดิม ไม่งั้นจะเห็นภาพเก่า
7. ภาพที่ AI ทำผิดจากสั่ง (เช่น คริสตัลวาดติดน้ำพุ) → แก้ด้วยสคริปต์ในขั้น 4 แล้วบอกผู้ใช้ว่าภาพต่างจากที่สั่งตรงไหน

## 4. แมพ (`map/map_lab.html`)
- **ใบสั่ง (RECIPE)** พิกัด 0–1 ตามภาพรวม `town_overview.png` → **กฎ + seed** วางของประดับ · seed เปลี่ยนแค่ของสุ่ม ผังหลักคงเดิม
- ทุกชิ้นมี **ป้ายเกม** (ชน/บัง/แสง/วาร์ป/โต้ตอบ/ผ่านได้) ใน `KIT_DEF` — ชนแค่ "ฐาน" (`FOOT`) ไม่ใช่ทั้งภาพ, ของ "บัง" จางลงเมื่อตัวละครอยู่ข้างหลัง
- **ความลึกฐาน `BASE`** ต่อชิ้น: ของฐานกว้าง (น้ำพุ .32, บ้าน .24) ต้องมีเงาเต็มฐาน; ต้นไม้ ~.04 — ถ้าของดู "ลอย" ให้ปรับค่านี้ก่อน
- เงาแดดต้อง **ลบรูปทรงวัตถุออกจากชั้นเงา** (destination-out) ไม่งั้นเงา "กิน" ตัวของเอง
- ขอบพื้นใช้ `soft()` (มาสก์เบลอ + เท texture) ไม่ใช้ stroke แข็ง · decal ห้ามโรยบนลาน/น้ำ (`onPaved`)
- ข้อความโต้ตอบเป็นข้อมูลในตาราง `TALK` · ส่งออก `town.json` สำหรับเกมจริง (`../Re-Ask`)

## 5. ตัวละคร + Rig (`rig/rig_lab.html`, `rig/pose_studio.html`)
- master → **ชีทชิ้นส่วน (C2)** → ตัด → กระดูก พ่อ-ลูก + pivot ถูกจุด (หลัก 2) → ท่า = ตัวเลขมุม, เคลื่อนไหว = คีย์ + เส้นโค้ง (หลัก 4)
- ชุด/หมวก/อาวุธ ใช้แม่แบบเดียว จุดยึดตรงกัน (หลัก 3) · ชั้นแสงเรืองแยกจากภาพ (หลัก 6, `make_glow.py`)
- ตัวละครใหม่: `assets/characters/<ชื่อ>/master_cut.png` แล้วเปิด `map_lab.html?hero=<ชื่อ>` เพื่อทดสอบสเกล

## 6. VFX (`vfx/*.html`, `vfx/vfx_runtime.js`)
- สองทาง: **procedural** (noise/voronoi + พารามิเตอร์ ดูวาดมือแต่โค้ดวาด — หลัก 11) หรือ **sprite sequence** (§4.5 + `cut_grid.py`)
- ความมันส์ = feedback ซ้อนชั้น: ตัวเลขดาเมจ + TOTAL คอมโบ, impact frame 1–3 เฟรม, hit-stop, สีประจำอาชีพ → VFX ชุดเดียว tint หลายสาย (หลัก 15)
- สีสกิลตัดกับโทนพื้นแมพ (หลัก 16)

## 7. ตรวจงานในเบราว์เซอร์ (กับดักที่เจอบ่อย)
- `preview_start` ชื่อ `labs` (พอร์ต 8765) · เติม `?v=N` ใหม่ทุกครั้งที่โหลด กันแคช HTML
- ตัวแปร `const` ในหน้าเรียกจาก javascript_tool ไม่ได้ → หน้าเปิด handle ดีบักไว้ เช่น `window.__town = {P, keys, step, blocked, MAP, near}`
- **pane ถูกซ่อน = requestAnimationFrame หยุด** (0 เฟรม) → กดปุ่มแล้วไม่ขยับไม่ใช่บั๊ก; ทดสอบด้วย `__town.step(1/60)` วนเอง
- ภาพหน้าจอเล็กเกินดูรายละเอียด → ก๊อป canvas ใน rAF ลง canvas ใหม่ ขยายเป็น overlay `position:fixed` แล้ว screenshot (ลบ overlay ทีหลัง)
- แก้ไฟล์ด้วย python replace: **อย่าเติมคอมเมนต์ `//` กลางบรรทัดที่มีโค้ดต่อท้าย** (เคยกลืน `const keys` ทั้งบรรทัด) — ใช้ `/* */` และเช็ค console ทุกครั้ง

- ได้บทเรียนใหม่ (กับดัก, ค่าที่ใช้ได้ผล) → เพิ่มลงไฟล์นี้; หลักการจากคลิป → `knowledge/PRINCIPLES.md`
